欢迎来到我的个人主页！这里将用于记录学习、研究与技术实践。

<!-- more -->

## 这个网站会分享什么

- 论文阅读过程中的理解和思考。
- 学习新知识、使用工具时整理的笔记。
- 项目实践中的方案、实现与复盘。

## 如何发布新文章

在网站根目录打开终端，执行：

```bash
pnpm exec hexo new "文章标题"
```

接着编辑 `source/_posts/` 下生成的 Markdown 文件。

文章顶部可以填写标题、日期、分类和标签。也可以添加 `description`，用于首页卡片摘要。

```yaml
title: 文章标题
date: 2026-11-23 16:00:00
categories:
  - 学习笔记
tags:
  - 工具使用
description: 用一两句话概括这篇文章。
```

## 本地预览

```bash
pnpm server
```

打开 <http://localhost:4000> 查看页面。确认无误后，将源码推送到 GitHub，Actions 就会自动构建和发布。
